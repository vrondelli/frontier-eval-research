## Functions

### parse_cohort(s: str) -> int
Strictly validates a cohort code string and returns the number
formed by its first two digits. Accepts ONLY exactly four digits and
nothing else, or exactly four digits, a single hyphen, and exactly three digits,
and nothing else. Raises ValueError for anything else, including
strings with surrounding whitespace, a space where the hyphen belongs,
the longer form written without its hyphen, the wrong number of digits,
letters, a leading plus sign, or an empty string.

### band_for(prefix: int) -> str
Returns the band name for a two-character code prefix number: the foundation
band for a prefix less than or equal to thirty-one, the standard band
for a prefix greater than thirty-one and less than or equal to
sixty-two, the advanced band for a prefix greater than sixty-two and
less than or equal to eighty-eight, and the honours band for a prefix
greater than eighty-eight.

### parse_charge(s: str) -> Decimal
Strictly parses a tuition or materials charge string. Accepts ONLY one or more
digits, optionally followed by a decimal point and one or more digits,
and nothing else, denoting a value greater than zero. Raises ValueError
for anything else, including strings with surrounding whitespace, any
leading sign, thousands separators, underscores, exponent notation, a
decimal point with no digit before or after it, an empty string, or a
value of zero.

### parse_waiver(s: str) -> Decimal
Strictly parses a waiver amount string. Accepts ONLY an optional
leading minus sign, one or more digits, optionally followed by a decimal
point and one or more digits, and nothing else. Zero and negative values
are accepted. Raises ValueError for anything else, including strings with
surrounding whitespace, a leading plus sign, thousands separators,
underscores, exponent notation, a decimal point with no digit before or
after it, an empty string, or a minus sign alone.

### parse_registered(s: str) -> tuple
Strictly validates a registration date string and returns a tuple of
the year, month, and day numbers. Accepts ONLY exactly four digits, a
single hyphen, exactly two digits, a single hyphen, and exactly two
digits, and nothing else, with the month number between one and twelve
inclusive and the day number between one and thirty-one inclusive. Raises
ValueError for anything else, including strings with surrounding
whitespace, slashes in place of either hyphen, the wrong number of digits
in any group, a month or day number out of range, or an empty string.

### is_eligible(year: int, month: int, day: int) -> bool
Returns true when the given registration date is earlier than or the same as the
cutoff date with year two thousand twenty-six, month eight, and day five,
and false when the registration date is later than that cutoff date.

### discount_for(combined: Decimal) -> Decimal
Returns the discount in whole currency units for a combined charge amount:
the smaller of fifteen hundredths of the combined charge and thirty,
computed exactly with no rounding.

### billable_amount(combined: Decimal, discount: Decimal) -> Decimal
Returns the billable amount in whole currency units: the combined charge minus
the discount, rounded upward to the nearest tenth of a unit: the smallest multiple of one tenth greater than or equal to that
difference. An exact multiple of one tenth is unchanged.

### subtotal_for(tier: str, billable: Decimal) -> Decimal
Returns the record subtotal in whole currency units before the uplift
increase: the band fixed levy plus the band rate multiplied by the
billable amount plus the per-record administration charge. The foundation band levy is one and its rate is seven hundredths; the standard band levy is three and its rate is twelve hundredths; the advanced band levy is six and its rate is nineteen hundredths; the honours band levy is ten and its rate is twenty-six hundredths; the administration charge is four for every record.

### apply_uplift_and_honours(subtotal: Decimal, is_top: bool) -> Decimal
Returns the subtotal increased by four hundredths of the subtotal. When
is_top is true, the flat honours charge of five is added after
that increase and is not itself increased by the uplift percentage.
When is_top is false, nothing further is added.

### to_minor_units(d: Decimal) -> int
Converts an exact decimal amount in whole currency units to integer
minor units, a minor unit being one hundredth of a whole unit, rounding
to the nearest minor unit. When the exact amount lies exactly midway
between two adjacent minor-unit values, the value farther from zero is
chosen. Uses exact decimal arithmetic, never binary floating point.

### mean_minor(total_minor: int, charged: int) -> int
Divides an integer minor-unit total by a record count, rounding to the
nearest integer. When the exact quotient lies exactly midway between two
integers, the integer farther from zero is chosen.

"""Course enrolment fee settlement."""

import re
from decimal import Decimal, ROUND_CEILING, ROUND_HALF_UP, localcontext


_COHORT = re.compile(r"(?:[0-9]{4}|[0-9]{4}-[0-9]{3})\Z")
_CHARGE = re.compile(r"[0-9]+(?:\.[0-9]+)?\Z")
_WAIVER = re.compile(r"-?[0-9]+(?:\.[0-9]+)?\Z")
_DATE = re.compile(r"([0-9]{4})-([0-9]{2})-([0-9]{2})\Z")


def _minor_units(amount):
    return int((amount * 100).quantize(Decimal("1"), rounding=ROUND_HALF_UP))


def _mean_minor(total, count):
    if count == 0:
        return 0
    sign = -1 if total < 0 else 1
    quotient, remainder = divmod(abs(total), count)
    if remainder * 2 >= count:
        quotient += 1
    return sign * quotient


def settle_enrolment(records):
    """Settle valid, eligible enrolment records and summarize their charges."""
    excluded = []
    fees = {}
    per_band = {}
    total_minor = 0

    for record in records:
        cohort = record["cohort"]
        tuition_text = record["tuition"]
        materials_text = record["materials"]
        waiver_text = record["waiver"]
        registered = record["registered"]

        cohort_match = _COHORT.fullmatch(cohort) if isinstance(cohort, str) else None
        tuition_match = _CHARGE.fullmatch(tuition_text) if isinstance(tuition_text, str) else None
        materials_match = _CHARGE.fullmatch(materials_text) if isinstance(materials_text, str) else None
        waiver_match = _WAIVER.fullmatch(waiver_text) if isinstance(waiver_text, str) else None
        date_match = _DATE.fullmatch(registered) if isinstance(registered, str) else None
        if not (cohort_match and tuition_match and materials_match and waiver_match and date_match):
            excluded.append(record["student"])
            continue

        date_parts = tuple(int(part) for part in date_match.groups())
        year, month, day = date_parts
        if not (1 <= month <= 12 and 1 <= day <= 31):
            excluded.append(record["student"])
            continue

        if date_parts > (2026, 8, 5):
            excluded.append(record["student"])
            continue

        prefix = int(cohort[:2])
        if prefix <= 31:
            band = "foundation"
        elif prefix <= 62:
            band = "standard"
        elif prefix <= 88:
            band = "advanced"
        else:
            band = "honours"

        tuition = Decimal(tuition_text)
        materials = Decimal(materials_text)
        waiver = Decimal(waiver_text)
        if tuition <= 0 or materials <= 0:
            excluded.append(record["student"])
            continue

        # Set precision from the supplied decimal strings so every operation,
        # including multiplication and the final quantization, remains exact.
        precision = len(tuition_text) + len(materials_text) + len(waiver_text) + 40
        with localcontext() as context:
            context.prec = max(50, precision)
            combined = tuition + materials
            discount = min(combined * Decimal("0.15"), Decimal("30"))
            billable = (combined - discount).quantize(Decimal("0.1"), rounding=ROUND_CEILING)
            levies_rates = {
                "foundation": (Decimal("1"), Decimal("0.07")),
                "standard": (Decimal("3"), Decimal("0.12")),
                "advanced": (Decimal("6"), Decimal("0.19")),
                "honours": (Decimal("10"), Decimal("0.26")),
            }
            levy, rate = levies_rates[band]
            subtotal = levy + rate * billable + Decimal("4")
            amount = subtotal * Decimal("1.04")
            if band == "honours":
                amount += Decimal("5")
            amount -= waiver
            charge = _minor_units(amount)

        fees[record["student"]] = charge
        total_minor += charge
        per_band[band] = per_band.get(band, 0) + charge

    charged = len(fees)
    return {
        "total_minor": total_minor,
        "charged": charged,
        "excluded": excluded,
        "fees": fees,
        "per_band": per_band,
        "mean_minor": _mean_minor(total_minor, charged),
    }

import unittest

from enrolment import settle_enrolment


def record(student, tuition="1", materials="1", cohort="3200",
           registered="2026-08-05", waiver="0"):
    return {
        "student": student,
        "tuition": tuition,
        "materials": materials,
        "cohort": cohort,
        "registered": registered,
        "waiver": waiver,
    }


class SettleEnrolmentTests(unittest.TestCase):
    def test_all_bands_and_exact_fee_arithmetic(self):
        # Foundation: 100 combined, 15 discount, 85 billable;
        # (1 + .07*85 + 4)*1.04 = 11.388 -> 1139 minor units.
        # Standard: 2 combined, .3 discount, 1.7 billable;
        # (3 + .12*1.7 + 4)*1.04 = 7.49216 -> 749.
        # Advanced: 60 combined, 9 discount, 51 billable;
        # (6 + .19*51 + 4)*1.04 = 20.4776 -> 2048.
        # Honours: 2 combined, .3 discount, 1.7 billable;
        # (10 + .26*1.7 + 4)*1.04 + 5 = 20.01968 -> 2002.
        records = [
            record("foundation", "80", "20", "3100"),
            record("standard", cohort="3200"),
            record("advanced", "40", "20", "6300"),
            record("honours", cohort="8900"),
        ]
        self.assertEqual(
            settle_enrolment(records),
            {
                "total_minor": 5938,
                "charged": 4,
                "excluded": [],
                "fees": {
                    "foundation": 1139,
                    "standard": 749,
                    "advanced": 2048,
                    "honours": 2002,
                },
                "per_band": {
                    "foundation": 1139,
                    "standard": 749,
                    "advanced": 2048,
                    "honours": 2002,
                },
                # 5938 / 4 = 1484.5, rounded away from zero.
                "mean_minor": 1485,
            },
        )

    def test_each_invalidity_excludes_once_in_input_order(self):
        records = [
            record("bad-cohort", cohort=" 3200"),
            record("bad-tuition", tuition="+1"),
            record("bad-materials", materials="1e0"),
            record("bad-waiver", waiver="-"),
            record("bad-date", registered="2026-02-00"),
            record("after-cutoff", registered="2026-08-06"),
            record("eligible-at-cutoff"),
        ]
        self.assertEqual(
            settle_enrolment(records),
            {
                "total_minor": 749,
                "charged": 1,
                "excluded": [
                    "bad-cohort", "bad-tuition", "bad-materials", "bad-waiver",
                    "bad-date", "after-cutoff",
                ],
                "fees": {"eligible-at-cutoff": 749},
                "per_band": {"standard": 749},
                "mean_minor": 749,
            },
        )

    def test_negative_waiver_and_half_mean(self):
        # The standard-band amount before waiver is 7.49216. Waivers 0 and
        # -0.01 therefore round to 749 and 750 minor units respectively.
        # Their mean is 749.5, which rounds away from zero to 750.
        self.assertEqual(
            settle_enrolment([
                record("base"),
                record("credit", waiver="-0.01"),
            ]),
            {
                "total_minor": 1499,
                "charged": 2,
                "excluded": [],
                "fees": {"base": 749, "credit": 750},
                "per_band": {"standard": 1499},
                "mean_minor": 750,
            },
        )

    def test_empty_and_all_excluded(self):
        empty = {
            "total_minor": 0,
            "charged": 0,
            "excluded": [],
            "fees": {},
            "per_band": {},
            "mean_minor": 0,
        }
        self.assertEqual(settle_enrolment([]), empty)
        all_excluded = dict(empty, excluded=["invalid"])
        self.assertEqual(settle_enrolment([record("invalid", tuition="0")]), all_excluded)


if __name__ == "__main__":
    unittest.main()
