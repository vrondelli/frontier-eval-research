## Functions

### parse_zone(s: str) -> int
Strictly validates a warehouse zone code string and returns the number
formed by its first two digits. Accepts ONLY exactly five digits and
nothing else, or exactly five digits, a single hyphen, and exactly three digits,
and nothing else. Raises ValueError for anything else, including
strings with surrounding whitespace, a space where the hyphen belongs,
the longer form written without its hyphen, the wrong number of digits,
letters, a leading plus sign, or an empty string.

### zone_for(prefix: int) -> str
Returns the zone class name for a two-character code prefix number: the local
zone class for a prefix less than or equal to nineteen, the regional zone class
for a prefix greater than nineteen and less than or equal to
forty-eight, the national zone class for a prefix greater than forty-eight and
less than or equal to seventy-three, and the express zone class for a prefix
greater than seventy-three.

### parse_charge(s: str) -> Decimal
Strictly parses a weight or volume charge string. Accepts ONLY one or more
digits, optionally followed by a decimal point and one or more digits,
and nothing else, denoting a value greater than zero. Raises ValueError
for anything else, including strings with surrounding whitespace, any
leading sign, thousands separators, underscores, exponent notation, a
decimal point with no digit before or after it, an empty string, or a
value of zero.

### parse_adjustment(s: str) -> Decimal
Strictly parses a adjustment amount string. Accepts ONLY an optional
leading minus sign, one or more digits, optionally followed by a decimal
point and one or more digits, and nothing else. Zero and negative values
are accepted. Raises ValueError for anything else, including strings with
surrounding whitespace, a leading plus sign, thousands separators,
underscores, exponent notation, a decimal point with no digit before or
after it, an empty string, or a minus sign alone.

### parse_packed(s: str) -> tuple
Strictly validates a packing date string and returns a tuple of
the year, month, and day numbers. Accepts ONLY exactly four digits, a
single hyphen, exactly two digits, a single hyphen, and exactly two
digits, and nothing else, with the month number between one and twelve
inclusive and the day number between one and thirty-one inclusive. Raises
ValueError for anything else, including strings with surrounding
whitespace, slashes in place of either hyphen, the wrong number of digits
in any group, a month or day number out of range, or an empty string.

### is_eligible(year: int, month: int, day: int) -> bool
Returns true when the given packing date is earlier than or the same as the
cutoff date with year two thousand twenty-five, month four, and day twenty,
and false when the packing date is later than that cutoff date.

### discount_for(combined: Decimal) -> Decimal
Returns the discount in whole currency units for a combined charge amount:
the smaller of nine hundredths of the combined charge and eighteen,
computed exactly with no rounding.

### billable_amount(combined: Decimal, discount: Decimal) -> Decimal
Returns the billable amount in whole currency units: the combined charge minus
the discount, rounded upward to the nearest quarter of a unit: the smallest multiple of one quarter greater than or equal to that
difference. An exact multiple of one quarter is unchanged.

### subtotal_for(tier: str, billable: Decimal) -> Decimal
Returns the record subtotal in whole currency units before the uplift
increase: the zone class fixed levy plus the zone class rate multiplied by the
billable amount plus the per-record packing charge. The local class levy is three and its rate is eleven hundredths; the regional class levy is five and its rate is seventeen hundredths; the national class levy is eight and its rate is twenty-four hundredths; the express class levy is thirteen and its rate is thirty-one hundredths; the packing charge is two for every record.

### apply_uplift_and_express(subtotal: Decimal, is_top: bool) -> Decimal
Returns the subtotal increased by seven hundredths of the subtotal. When
is_top is true, the flat express charge of six is added after
that increase and is not itself increased by the uplift percentage.
When is_top is false, nothing further is added.

### to_minor_units(d: Decimal) -> int
Converts an exact decimal amount in whole currency units to integer

to the nearest minor unit. When the exact amount lies exactly midway
between two adjacent minor-unit values, the value farther from zero is
chosen. Uses exact decimal arithmetic, never binary floating point.

### mean_minor(total_minor: int, charged: int) -> int
Divides an integer minor-unit total by a record count, rounding to the

    """Nearest integer, resolving an exact half away from zero."""
    sign = -1 if value < 0 else 1
    numerator = abs(value.numerator)
    denominator = value.denominator
    quotient, remainder = divmod(numerator, denominator)
    if 2 * remainder >= denominator:
        quotient += 1
    return sign * quotient


def settle_picking(records):
    charges = {}
    per_zone = {}
    excluded = []
    total_minor = 0

    for record in records:
        order = record["order"]
        zone = record["zone"]
        packed = record["packed"]
        weight = record["weight"]
        volume = record["volume"]
        adjustment = record["adjustment"]

        match = _ZONE.fullmatch(zone)
        date_match = _PACKED.fullmatch(packed)
        if not match or not date_match:
            excluded.append(order)
            continue

        prefix = int(zone[:2])
        year, month, day = map(int, date_match.groups())
        if not (1 <= month <= 12 and 1 <= day <= 31):
            excluded.append(order)
            continue

        if not _CHARGE.fullmatch(weight) or not _CHARGE.fullmatch(volume):
            excluded.append(order)
            continue
        if not _ADJUSTMENT.fullmatch(adjustment):
            excluded.append(order)
            continue

        weight_value = _decimal_fraction(weight)
        volume_value = _decimal_fraction(volume)
        adjustment_value = _decimal_fraction(adjustment)
        if weight_value <= 0 or volume_value <= 0:
            excluded.append(order)
            continue
        if (year, month, day) > (2025, 4, 20):
            excluded.append(order)
            continue

        tier, levy, rate = None, None, None
        for upper_bound, name, fixed_levy, tier_rate in _TIERS:
            if prefix <= upper_bound:
                tier, levy, rate = name, fixed_levy, tier_rate
                break

        combined = weight_value + volume_value
        discount = min(combined * Fraction(9, 100), Fraction(18))
        raw_billable = combined - discount
        # The least quarter multiple at or above x is ceil(4*x) / 4.
        quarter_numerator = raw_billable.numerator * 4
        quarter_multiple = -(-quarter_numerator // raw_billable.denominator)
        billable = Fraction(quarter_multiple, 4)

        subtotal = Fraction(levy + 2) + rate * billable
        amount = subtotal * Fraction(107, 100)
        if tier == "express":
            amount += 6
        amount -= adjustment_value

        charge = _round_away(amount * 100)
        charges[order] = charge
        per_zone[tier] = per_zone.get(tier, 0) + charge
        total_minor += charge

    charged = len(charges)
    mean = _round_away(Fraction(total_minor, charged)) if charged else 0
    return {
        "total_minor": total_minor,
        "charged": charged,
        "excluded": excluded,
        "charges": charges,
        "per_zone": per_zone,
        "mean_minor": mean,
    }
