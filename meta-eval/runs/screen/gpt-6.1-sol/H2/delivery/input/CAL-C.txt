Title: Flaky-test dashboard
Collect pass/fail history for every test into a web page. Show a table sorted
by flip rate (fraction of runs whose result differs from the previous run),
with red/yellow/green badges and a 30-day sparkline per test. Engineers open
the page during triage to see which tests flip most.
Test of the idea: give the page to one team for a month and ask whether triage
got faster. Cost: one small web service.
