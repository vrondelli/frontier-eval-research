# Public archive transformations

The local private evidence retains original transcripts, native files, capture-fault snapshots and controller receipts. `ALL-ATTEMPT-CUSTODY.json` audits those original bytes against the fixed attempt policies and saved delivery inventories.

The public ZIP contains targeted sanitized transcript copies. Memory-search command/results and private memory citations are omitted from those copies. `PRIVACY-REDACTIONS.json` lists original and sanitized hashes and the affected events. This is not a claim that the public ZIP contains complete raw transcripts.

`RELEASE-EXCLUSIONS.json` lists excluded caches, local environments, credential filenames, generated media and duplicate output archives. Intended model-delivered ZIPartifacts remain included after bounded nested privacy/secret/path scans; `NESTED-ARCHIVE-REVIEW.json` records their original/public hashes. An unchanged scan preserves exact ZIPbytes. Any unsafe/private member sanitization or archive exclusion is explicit. Original sourceless public-task bytecode outside cache directories is retained when required by packet manifests.

`RELEASE-MANIFEST.json` binds the bytes actually present in the public ZIP. `verify_release.py` checks those bytes, public input packets and finite owner control reproduction. It records adjudicated exclusions and does not claim every historical positive control constitutes full-task gold. Public redactions/exclusions must not be misreported as changes to private original model deliveries.

Current author/scoring defaults are recorded in `SCORING-POLICY.json`: clean captureV2 and adjudication-aware owner scorer. Frozen old runners remain available only to reproduce their historical receipts and disclosed capture faults.
