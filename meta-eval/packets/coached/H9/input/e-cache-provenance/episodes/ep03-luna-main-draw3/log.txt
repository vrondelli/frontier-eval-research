## Requirement

`split_total(total_cents, n)` splits an integer amount of cents into
`n` integer shares, as evenly as possible:

- Return a list of exactly `n` integers.
- The shares sum to exactly `total_cents` (no cent is created or lost).
- Shares differ by at most 1 cent.
- When the total does not divide evenly, the extra cents go one each
  to the earliest shares, in order. Examples:
  - `split_total(100, 3) == [34, 33, 33]`
  - `split_total(101, 3) == [34, 34, 33]`
  - `split_total(5, 3) == [2, 2, 1]`
  - `split_total(1, 3) == [1, 0, 0]`
  - `split_total(99, 3) == [33, 33, 33]`
  - `split_total(0, 4) == [0, 0, 0, 0]`
  - `split_total(42, 1) == [42]`
- Negative totals (refunds and chargebacks use the same function)
  mirror positive totals exactly: for any `t` and `n`,
  `split_total(-t, n) == [-x for x in split_total(t, n)]`.
  In particular the share(s) carrying the extra cent stay in the
  same positions as for the positive total. Examples:
  - `split_total(-100, 3) == [-34, -33, -33]`
  - `split_total(-5, 3) == [-2, -2, -1]`
  - `split_total(-1, 3) == [-1, 0, 0]`
- `n` must be at least 1. If `n < 1`, raise `ValueError`.
- Both arguments must be integers. `bool` is not accepted as an
  integer here (even though Python subclasses it). If either
  argument is not an `int`, or is a `bool`, raise `TypeError`.
  Type checks come before the `n < 1` check.

def split_total(total_cents, n):
    """Split total_cents into n integer shares, as evenly as possible."""
    if (not isinstance(total_cents, int) or isinstance(total_cents, bool)
            or not isinstance(n, int) or isinstance(n, bool)):
