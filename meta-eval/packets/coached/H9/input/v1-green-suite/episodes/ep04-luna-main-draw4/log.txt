## Functions

### parse_code(s: str) -> int
Strictly validates a membership code string and returns the number
formed by its first two digits. Accepts ONLY exactly six digits and
nothing else, or exactly six digits, a single hyphen, and exactly two
digits, and nothing else. Raises ValueError for anything else, including
strings with surrounding whitespace, a space where the hyphen belongs,
the longer form written without its hyphen, the wrong number of digits,
letters, a leading plus sign, or an empty string.

### tier_for(prefix: int) -> str
Returns the tier name for a two-character code prefix number: the junior
tier for a prefix less than or equal to twenty-four, the regular tier
for a prefix greater than twenty-four and less than or equal to
fifty-seven, the senior tier for a prefix greater than fifty-seven and
less than or equal to eighty-one, and the premium tier for a prefix
greater than eighty-one.

### parse_charge(s: str) -> Decimal
Strictly parses a base or damage charge string. Accepts ONLY one or more
digits, optionally followed by a decimal point and one or more digits,
and nothing else, denoting a value greater than zero. Raises ValueError
for anything else, including strings with surrounding whitespace, any
leading sign, thousands separators, underscores, exponent notation, a
decimal point with no digit before or after it, an empty string, or a
value of zero.

### parse_credit(s: str) -> Decimal
Strictly parses a credit amount string. Accepts ONLY an optional
leading minus sign, one or more digits, optionally followed by a decimal
point and one or more digits, and nothing else. Zero and negative values
are accepted. Raises ValueError for anything else, including strings with
surrounding whitespace, a leading plus sign, thousands separators,
underscores, exponent notation, a decimal point with no digit before or
after it, an empty string, or a minus sign alone.

### parse_borrowed(s: str) -> tuple
Strictly validates a borrow date string and returns a tuple of
the year, month, and day numbers. Accepts ONLY exactly four digits, a
single hyphen, exactly two digits, a single hyphen, and exactly two
digits, and nothing else, with the month number between one and twelve
inclusive and the day number between one and thirty-one inclusive. Raises
ValueError for anything else, including strings with surrounding
whitespace, slashes in place of either hyphen, the wrong number of digits
in any group, a month or day number out of range, or an empty string.

### is_eligible(year: int, month: int, day: int) -> bool
Returns true when the given borrow date is earlier than or the same as the
cutoff date with year two thousand twenty-four, month nine, and day
fifteen, and false when the borrow date is later than that cutoff date.

### discount_for(combined: Decimal) -> Decimal
Returns the discount in whole currency units for a combined charge amount:
the smaller of twelve hundredths of the combined charge and twenty-five,
computed exactly with no rounding.

### billable_amount(combined: Decimal, discount: Decimal) -> Decimal
Returns the billable amount in whole currency units: the combined charge minus
the discount, rounded upward to the nearest fifth of a unit, that is, the
smallest multiple of one fifth greater than or equal to that
difference. An exact multiple of one fifth is unchanged.

### subtotal_for(tier: str, billable: Decimal) -> Decimal
Returns the record subtotal in whole currency units before the uplift
increase: the tier fixed levy plus the tier rate multiplied by the
billable amount plus the per-record handling charge. The junior levy is
two and its rate is nine hundredths; the regular levy is four and
its rate is fourteen hundredths; the senior levy is seven and its rate
is twenty-one hundredths; the premium levy is eleven and its rate is
twenty-eight hundredths; the handling charge is three for every record.

### apply_uplift_and_premium(subtotal: Decimal, is_premium: bool) -> Decimal
Returns the subtotal increased by five hundredths of the subtotal. When
is_premium is true, the flat premium charge of four is added after
that increase and is not itself increased by the uplift percentage.
When is_premium is false, nothing further is added.

### to_minor_units(d: Decimal) -> int
Converts an exact decimal amount in whole currency units to integer

to the nearest minor unit. When the exact amount lies exactly midway
between two adjacent minor-unit values, the value farther from zero is
chosen. Uses exact decimal arithmetic, never binary floating point.

### mean_minor(total_minor: int, charged: int) -> int

"""Library fines settlement."""

from fractions import Fraction
import re
from decimal import Decimal


_CODE_RE = re.compile(r"(?:[0-9]{6}|[0-9]{6}-[0-9]{2})\Z")
_CHARGE_RE = re.compile(r"[0-9]+(?:\.[0-9]+)?\Z")
_CREDIT_RE = re.compile(r"-?[0-9]+(?:\.[0-9]+)?\Z")
_DATE_RE = re.compile(r"([0-9]{4})-([0-9]{2})-([0-9]{2})\Z")


def _round_fraction_away_from_zero(value):
    """Round a Fraction to the nearest integer, resolving ties away from zero."""
    sign = -1 if value < 0 else 1
    numerator = abs(value.numerator)
    quotient, remainder = divmod(numerator, value.denominator)
    if remainder * 2 >= value.denominator:
        quotient += 1
    return sign * quotient


def _ceil_fraction(value):
    return -((-value.numerator) // value.denominator)


def settle_fines(records):
    """Settle all eligible, valid records and summarize their fines."""
    excluded = []
    fines = {}
    per_tier = {}

    levies = {
        "junior": 2,
        "regular": 4,
        "senior": 7,
        "premium": 11,
    }
    rates = {
        "junior": Fraction(9, 100),
        "regular": Fraction(14, 100),
        "senior": Fraction(21, 100),
        "premium": Fraction(28, 100),
    }

    for record in records:
        try:
            code = record["code"]
            if not _CODE_RE.fullmatch(code):
                raise ValueError("invalid membership code")
            prefix = int(code[:2])

            charge_strings = (record["base"], record["damage"])
            if any(not _CHARGE_RE.fullmatch(value) for value in charge_strings):
                raise ValueError("invalid charge")
            base, damage = (Fraction(Decimal(value)) for value in charge_strings)
            if base <= 0 or damage <= 0:
                raise ValueError("charges must be positive")

            credit_string = record["credit"]
            if not _CREDIT_RE.fullmatch(credit_string):
                raise ValueError("invalid credit")
            credit = Fraction(Decimal(credit_string))

            date_match = _DATE_RE.fullmatch(record["borrowed"])
            if not date_match:
                raise ValueError("invalid borrow date")
            year, month, day = map(int, date_match.groups())
            if not (1 <= month <= 12 and 1 <= day <= 31):
                raise ValueError("invalid borrow date")
            if (year, month, day) > (2024, 9, 15):
                raise ValueError("borrow date is after the cutoff")
        except ValueError:
            excluded.append(record["patron"])
            continue

        if prefix <= 24:
            tier = "junior"
        elif prefix <= 57:
            tier = "regular"
        elif prefix <= 81:
            tier = "senior"
        else:
            tier = "premium"
        combined = base + damage
        discount = min(combined * Fraction(12, 100), Fraction(25))
        raw_billable = combined - discount
        # Round upward to a multiple of one fifth, without decimal-context rounding.
        billable = Fraction(_ceil_fraction(raw_billable * 5), 5)

        subtotal = Fraction(levies[tier] + 3) + rates[tier] * billable
        amount = subtotal * Fraction(105, 100)
        if tier == "premium":
            amount += 4
        amount -= credit

        fine = _round_fraction_away_from_zero(amount * 100)
        patron = record["patron"]
        fines[patron] = fine
        per_tier[tier] = per_tier.get(tier, 0) + fine

    total_minor = sum(fines.values())
    charged = len(fines)
    mean_minor = (
        _round_fraction_away_from_zero(Fraction(total_minor, charged))
        if charged
        else 0
    )

    return {
        "total_minor": total_minor,
        "charged": charged,
        "excluded": excluded,
        "fines": fines,
        "per_tier": per_tier,
        "mean_minor": mean_minor,
    }
