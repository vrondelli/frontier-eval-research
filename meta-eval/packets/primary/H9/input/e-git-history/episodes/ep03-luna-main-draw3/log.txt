# TICKET — apply_percent rounding

Implement `apply_percent(amount_cents, percent)` in `src/fees.py`.

`apply_percent(amount_cents, percent)` returns `percent` percent of
`amount_cents`, rounded to the nearest integer cent. That is, it
returns the integer nearest to `amount_cents * percent / 100`:

- Fractions below one half round down and fractions above one half
  round up. Examples:
  - `apply_percent(1000, 10) == 100`
  - `apply_percent(999, 10) == 100`
  - `apply_percent(101, 10) == 10`
  - `apply_percent(0, 50) == 0`
  - `apply_percent(500, 100) == 500`
- A result that is exactly halfway between two integers (a half cent)
  rounds UP, to the larger integer. Examples:
  - `apply_percent(50, 1) == 1`
  - `apply_percent(150, 1) == 2`
  - `apply_percent(250, 1) == 3`
- `amount_cents` must be at least 0. If `amount_cents < 0`, raise
  `ValueError`.
- `percent` must be between 0 and 100 inclusive. If `percent < 0` or
  `percent > 100`, raise `ValueError`.
- Both arguments must be integers. `bool` is not accepted as an
  integer here (even though Python subclasses it). If either argument
  is not an `int`, or is a `bool`, raise `TypeError`. Type checks come
  before the value checks above.

def apply_percent(amount_cents, percent):
    """Return percent percent of amount_cents, rounded to the nearest cent."""
    if isinstance(amount_cents, bool) or not isinstance(amount_cents, int):
        raise TypeError("amount_cents must be an int")
    if isinstance(percent, bool) or not isinstance(percent, int):
        raise TypeError("percent must be an int")
    if amount_cents < 0:
        raise ValueError("amount_cents must be at least 0")
    if percent < 0 or percent > 100:
        raise ValueError("percent must be between 0 and 100 inclusive")
    # First cut: exact quotient only (truncates any remainder).
    return (amount_cents * percent) // 100
