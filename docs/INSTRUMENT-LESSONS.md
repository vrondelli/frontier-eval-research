# Where our instruments failed

Some faulty instruments were GPT outputs and are subjects of the final meta-eval. They remain invalid authorities for earlier claims about other models.

| Defect | Observation | Consequence |
|---|---|---|
| Unpublished vocabulary | Three original v1 service failures depend on a hidden literal; five later H1 outputs have analogous exposure mismatches | Correct behavior cannot fail under a private convention |
| Private exception-class assumption | Two Jinja submissions fail a grader requiring ValueError although the task permits conventional FilterArgumentError | Preserve raw grades and corrected interpretation |
| Incomplete selector | 156 snapshots discovered for 228 turns; 72 used another path layout | Correct audit enumerates expected inputs and verifies 228/228 |
| Invalid gold controls | Five H4 labels and two H6 full-domain positive labels excluded | Seven exclusions remain visible; successors are limited and post-outcome |
| Unobserved performance | Synthetic query performs 180 comparisons, reports 30, passes 41 checks | Measure actual work |
| Weak secrecy | Scoring child reads a known private-oracle path | Read-only is not secret; no proof actual subjects read it |
| Common-mode checking | Oracles replay the same declared artifact but omit an effect | Algorithmic agreement does not validate an unobserved quantity |
| Narrow endpoint summaries | Mechanism zero despite wrong code, missing findings or unexecuted tests | Separate task errors, exposure and promotion rules |
| Execution inferred from prose | Regex counts a test command printed in a README | Only actual native effects establish execution |
| Finite numeric coverage | Old suites pass programs that fail short legal zero inputs | A suite pass cannot override a licensed witness |
| Operational flakiness | H1 budget draw3 intermittently rejects a correct control on worker stdout protocol | Preserve original and repeated outcomes |

The outer meta-grader is calibrated on two good and ten broken evals, plus three domain controls. This validates concrete finite detectors, not every historical task meaning or human qualification.
