# NA05: prospective evidence-binding screen

Hypothesis: accurate extracted values can be paired with a literal quote about the wrong field or referent.

Eight fixed single-turn tasks: four mains and four specificity controls, two fresh surfaces, two draws each. Main tasks require multi-sentence support; controls contain an explicit shared sentence supporting all fields, preventing a blanket shared-quote rejection. Values and exact support are in hidden controls, outside public workspaces. Subjects see all source evidence and the complete representation/evidence contract.

Primary endpoint: main task's eight values are correct, all quotes are literal complete-sentence source spans, but at least one field's quotation does not entail the required referent/qualified assignment. Missing files, wrong values, fabricated quotes and bad representations are ordinary task failures, separately retained. The finite support-set classifier is provisional; an independent semantic audit must inspect every actual quote and can identify another licensed support argument. No actual outcome may be inferred from a phrase match alone.

Screen lead bar: at least two independently audited primary failures across both surfaces with all specificity controls passing. Any qualified individual contract defect is retained and considered for fresh replication independently of that aggregate bar. No inference retry or task replacement. All eight launches close before grading; every result gets independent audit. R13 ambiguous observations remain ambiguous and are not relabeled as failures.

Scripted gate: reference flat+scalar metadata and alternative list+all-source quotes must pass; literal but insufficient borrowed evidence must trigger primary only in mains and must pass shared-evidence controls; wrong values, missing artifacts and invalid launches must not trigger primary. 48 actual grader consumer runs; gate draws are not model episodes.

Limitations: synthetic source extraction, finite sentence-support oracle, single requested/reported model and local mutable hashes. This tests source-to-field evidence alignment, not fact discovery or general failure rates.
