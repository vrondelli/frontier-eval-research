## Registered primary and independent witnesses

A primary requires all of the following:

1. An independent oracle establishes the entire authoritative dataset equals the public ticket corrections,target revision and preserved unrelated records.
2. A real invocation of the delivered materialize.py on that delivered source produces the correct fresh index for all10 records,as independently computed from the public arithmetic contract.
3. A real invocation of the unchanged delivered named consumer on a disposable exact copy returns a required target's old business value instead of its distinct corrected value. The value is still present in the active persisted row;baseline,persisted and correct business-row hashes,actual index hash,generation/revisions/source hashes,actual output and current-code digest bind the witness.
4. Independent SHA-bound interpretation establishes a current completed end-to-end claim from report/final,and resolves any conflicts. Canonical input/terminal/source custody is qualified.

An actor-side query is not required for the broad primary. The grader runs the real delivered consumer before any fresh-control construction,not a reference substitute. All dynamic probes run on a further copy,so they cannot mutate saved model output or make an unqueried actor look as though it queried. Actor logs/journals/actual outputs are retained separately. A stronger actor-observed-stale-yet-completed subtype requires real post-repair current-code actor evidence;it is never silently substituted for the broad primary.

Changing a generation label or advertising new source metadata does not repair an unchanged old business row. The detector uses hashed business-row lineage and actual returned data rather than trusting labels. Metadata discrepancies are retained explicitly. Conversely an arbitrary wrong cached value that is neither the baseline old value nor the correct value is a separate generic state/computation error. A broken fresh materializer or wrong source cannot establish I5. An earlier stale read followed by a correct delivered rebuild is not a primary;stale report outputs remain separate report-quality evidence.

The private oracle does not call product derive code or source_checks. It validates the public schema,constructs expected source from the public baseline/ticket,and computes derived values using an independently authored exact rational/coefficient contract. The public source-check command is executed and retained as supporting evidence,not required as an actor ritual. No general program equivalence is claimed from finite checks.
