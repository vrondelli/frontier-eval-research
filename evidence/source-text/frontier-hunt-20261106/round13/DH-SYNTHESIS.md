## Numeric IO lead

The public contract described mathematical signed integers without a magnitude bound. An independently constructed valid input of about 5 KB contains one 5001-digit integer. A count operation should return 1, so this witness isolates input conversion rather than difficult arithmetic. A second witness uses the integral JSON exponent `1e5000` and a singleton sum to isolate decimal output conversion. Both satisfy the normative numeric schema. Four paired interventions on two preserved seed programs changed only the child process's `PYTHONINTMAXSTRDIGITS` setting and rescued the failures. A correctly implemented model output passed both default and intervention conditions.

The observed runtime was Python 3.14.4 with the default 4300-digit decimal conversion limit. That runtime limit is documented in [Python's integer conversion documentation](https://docs.python.org/3.14/builtins/stdtypes.html#integer-string-conversion-length-limitation). The application defect is inheriting an undeclared restriction under an unbounded contract. This does not show inability to calculate large integers, and bypassing a runtime guard is not a general security recommendation.

The fresh numeric instrument used new tournament and polynomial task surfaces, four unbounded mains and two explicitly bounded controls. Public prompts did not name the old examples, digit threshold or repair. Reader-only and writer-only witnesses, exact numeric parsing, known-good implementations and adversarial programs qualified the instrument before draws. An invalid-input guard initially overrejected licensed error envelopes; the old 144-case author and independent evidence was archived before a narrow pre-inference repair. The final 156-case author gate and independent delta review are bound in the fresh freeze.

## Instrument review and retained problems

An instrument review checks whether our prompt, grader, runtime and evidence actually support the claimed failure. It is necessary here because DH19's original grader rejected all eight outputs by requiring an unlicensed outer `fields` wrapper. Seven were clearly licensed pure flat maps; the eighth mixed flat fields with scalar metadata and remains format-ambiguous. A separately labeled posthoc normalization diagnostic passed the seven pure flat maps. All 64 requested field values, quotations and entailments were manually checked and correct. The original grades were retained, not silently repaired into new prospective results.

Other pre-inference repairs included delayed HTTP evidence capture, browser runtime dependencies, responsive viewport coverage, state-restart coverage and native worker lifecycle accounting. A tmpfs storage incident confounded four original task completions; ten never-launched setup failures were recovered without retrying attempted inference. The original timeout and failed infrastructure probes remain in the evidence. A concurrent research task replaced the shared runner path; exact original bytes were recovered by hash into `common-dh`, and later DH runtime copies used their own namespace. Original subject artifacts and frozen lane sources remain unchanged.
