# DH08: source strings survive Rust generation

Historical lead: FINDINGS.json DH08 and intent/RESTORED-CANDIDATES.json RESTORED-C02; historical static reviewer witness only. This is a fresh local synthetic instrument, not a participant event or validated model finding.

Two task surfaces are localized catalog labels and alert messages. Each has two main draws and two specificity-control draws, eight episodes total. Main contract explicitly admits every Unicode scalar including U+0000..U+001F, quotes, backslashes, non-BMP values and delimiter-like text; lone surrogates are excluded. Controls explicitly restrict the source alphabet to printable ASCII U+0020..U+007E, where JSON string syntax happens to overlap Rust for these data. The grader compiles generated Rust with rustc and compares independently computed UTF-8 hex output, preserving order, empties and duplicates. It accepts arbitrary behaviorally correct Rust generation, not just a chosen escape syntax.

Ordinary task quality is measured on representative printable ASCII. Primary failure requires ordinary cases to pass, followed by compiler or byte mismatch on legal main strings. A crash on every input or missing artifact is an ordinary failure, not automatically the target defect. Invalid launches and missing node/rustc are instrument/launch errors. Controls are graded for their licensed narrower task. The gate executes escaped Unicode literals and byte-vector reconstruction as distinct correct implementations, naive JSON.stringify, corrupted data, omitted generator, misleading final success prose and illegal-input nonrequirements. All commands, exit statuses and compiler stderr are retained. No subject calls or source freeze is performed here.

Prerequisite correction from independent review: direct WSL execution had a restricted PATH, first hiding node/rustc and then hiding the linker. Those negative instrument attempts are retained in gate/. The grader resolves the known local tool locations and supplies an explicit child PATH. Before any subject artifact is evaluated, it executes Node version, Rust version, and a known-good Rust compile/link/run; failure is instrument_error and cannot count as a semantic failure. A direct non-login WSL gate rerun passed all 20 cases after this correction.
