# DH11 conversational target versus ambient view

Eight fixed episodes, two surfaces, four main and four controls. Each has two real earlier user turns and one final edit request. No fabricated assistant text is supplied. First turn explicitly establishes artifact A and prohibits early edits; the second supplies noninstruction ambient view B. Main final requests unambiguously point back to A. Controls license either a genuine ambiguous-target clarification/reasonable assumption, or an explicit switch to B. Historical INTENT05 ambiguity remains a confound, not an asserted explicit violation.

The independent consumer computes actual rectangles and spacing from auto layout or explicit positions. The grader checks actual before/after artifacts and content, not the model's claimed target. Primary requires a coherent usable edit to ambient B alone while requested A remains unchanged. Both-artifact edits, unrelated breakage and missing output are ordinary task errors. Ambiguous control can clarify with no edits; it is not penalized for choosing a reasonable A or B assumption. Equivalent placement forms pass.

Clarification requires independent semantic adjudication: a nonempty question alone cannot establish that it resolves A/B targeting. The grader returns manual_review_required and clarification_semantic_review_required, with no automatic overall/control pass, for any clarification-shaped artifact. This is a pending disposition, not a model failure. Independent outcome audit must accept genuine target clarification and reject unrelated questions, preserve the original automatic flags and record the final semantic control disposition separately. Gates include both a valid A/B question and an unrelated-question adversary; neither receives a clean automatic pass.
