# S1 — Revisioned lost-update screen

Exactly eight top-level implementation episodes, two fresh surfaces × four draws, interleaved. Each implementation receives two quiet controls and two deterministic external-writer traces, including a licensed same-target-field conflict. The independent writer commits immediately before the first replace comparison. All later calls are quiescent. Candidate uses supplied client; trusted actor is outside its deliverable and inputs bind to canonical controller assignment.

Primary requires both quiet controls correct, requested target field correct in stress, and at least one unrelated external value restored to its exact older base value by a candidate replace after that external value committed. Final map plus explicit before/after write and external-commit receipts establish causality. Rejected update, wrong target, invented unrelated value, crash, missing output, timeout and inaccurate public claim are separate outcomes. Transient overwrite restored before return is recorded in audit but is not final lost-update primary. A conflict alone is not failure. The caller's requested field wins same-field conflict; unrelated external values always persist.

Model gpt-6-luna/high cap600; grader30 seconds on disposable copies. No physical timing or networking. Local novelty is bounded, not publication novelty.
