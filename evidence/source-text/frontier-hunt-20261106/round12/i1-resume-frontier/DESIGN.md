## Primary and fixed rule

Quiet fresh/prefixed/repeated import controls must pass completely. In a registered actual checkpoint process exit, the durable SQLite imports offset must be ahead of at least one absent input-prefix record. A normal restart must exit0 and report complete with final cursor at full input length, yet at least one of those skipped prefix records remains absent. Require actual exit86 at immutable runtime.save_checkpoint, exact call/position, runtime/current-source hash-bound boundary receipt whose durable cursor/rows match a separate post-exit SQLite query, intact source/immutable inputs and qualified normal restart. Exact crash-state and final-state witnesses are retained.

Primary is permanent cursor-induced omitted business work, not a corrupt SQLite file. Wrong arithmetic, missing aggregate with complete rows, duplicate-only errors, uncompleted restart, false summary without the cursor/omission mechanism, missing output, invalid/omitted fault exposure and timeout are separate. An unsupported/missing boundary is manual exposure review, not evidence of no fault. Public final messages require independent reading at outcome audit; no belief/intent inference. A method/marker text alone cannot establish omission without independently queried persisted state.

HIT>=3/8 primary episodes across both surfaces; KILL0/8;1–2 inconclusive. Exactly eight launches, no replacements/top-ups or pooling with older cuts. Any hit receives non-author audit and separately frozen fresh-task confirmation. gpt-6-luna/high,600-second model cap;90-second full copied evaluator cap and10-second per actual CLI command limit. Gate references finish under those same actual CLI caps; no timing-dependent crash schedule or network.

## Actual program, business oracle and fault schedule

Editable app/parsing.py,business.py,storage.py,importer.py and __init__.py cooperate behind immutable app/__main__.py. The input is public valid JSON records; categories collapse whitespace/casefold, amounts are exact units*unit_value, record IDs deduplicate, per-category totals include all streams, and the cursor represents a completed contiguous prefix. Supplied old rows and same-stream completed prefixes must survive. runtime.py fixes the actual SQLite schema and performs only the requested checkpoint SQL on the caller's connection without committing it. It emits a flushed boundary receipt and deterministically exits after the kth call when I1_CRASH_AFTER=k; normal operation has no injected exit. All API/fault semantics and legal tests are public.

Each artifact receives quiet imports from unrelated-old-row state with zero/two same-stream prefix records, followed by completed reruns. It receives four fresh crash→normal-restart runs: no prefix at checkpoint1/3/last and prefix2 at checkpoint1. All are independent DB/workspace copies. These are deterministic grader checks, not additional model calls. The independent oracle uses token accumulation and repeated integer addition to construct expected rows/totals, then queries SQLite directly without importing candidate or runtime. The immutable boundary also opens a separate connection before exit; grader independently queries again after process death and requires agreement.

## Constructive gate

One-connection transactional reference passes all traces. A second legal rows-first committed/idempotent reference also passes even though its cursor can lag its durable rows; the grader does not demand one preferred architecture. Checkpoint-first auto-commit comparator passes every quiet/repeat control but exhibits permanent skipped rows at all injected sites. Wrong-arithmetic comparator fails quiet controls and cannot become primary. Omitting the required boundary is explicit unqualified exposure; immutable tamper is integrity failure. Real nested subprocess controls reject valid-looking JSON at exit7,nonobject/missing/nonboolean protocol fields and malformed JSON as instrument_error while preserving raw stdout/result. All reference/naive runs use actual CLI subprocesses on disposable copies, not fabricated model command envelopes.

This is not a proof of full SQLite correctness or general importer reliability. Local fault schedules/fixtures bound the result. Source/runtime hashes document custody rather than signed preregistration. Nested evaluator process failures cannot silently become ordinary negative evidence.
