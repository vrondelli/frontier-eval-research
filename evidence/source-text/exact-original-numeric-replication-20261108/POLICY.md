# Conditional replication policy, fixed before pilot outcomes

This package is prepared while the two-model original-task pilot remains blinded. It authorizes no launch by itself. The root coordinator must first finish both pilot attempts and independently confirm each qualifying model against the original public contract, saved source custody and an independent lexical oracle.

A model qualifies only if its warehouse-control-1 pilot turn completed normally, the original protected public files remain unchanged, the frozen valid 191-byte huge-zero request fails the required CLI/result contract, the frozen canonical-zero contrast succeeds, and independent source/cause review establishes a model implementation error rather than a transport, staging, grader, resource or interpretation defect. A failed or incomplete native launch does not qualify for automatic replication. No pilot attempt is removed or replaced.

For each qualifying model, run exactly two fresh native draws on the exact original bounded `energy-control-1` task. Eligible models are only gpt-6-astra and gpt-6.1-sol, each with high reasoning effort, 600 seconds, no retry and a new chat/workspace per draw. If one model qualifies, the replication denominator is two; if both qualify, it is four; if neither qualifies, there are zero replication calls. Freeze and launch the entire selected batch, retain every attempt and wait for the whole batch to terminate before grading. Do not stop or expand the sample based on its first outcome.

Actors receive only the unchanged original energy-control-1 public template and saved original prompt. They receive no pilot code, result, zero-exponent hint, private witness, policy or repair feedback. Existing native global configuration/tools remain available and must be disclosed/audited as in the pilot. No new runtime public file is added.

The task was selected prospectively as an original different surface in the same measurement/count family. Its README and schemas explicitly bound every measurement to [-1000,1000] and permit mathematically integral JSON number encodings. The archived private 177-byte request contains one huge-exponent spelling of mathematical zero; the other measurements are 0, 1.0 and -2.0, all within the bound. Its archived 156-byte contrast changes only that one zero spelling. Both require energy_reports counts 1 and 3. Thus there is no infeasible unbounded arithmetic demand and no rule about maximum written exponent is introduced. The exact archived 177/156 bytes are retained, including the ordinary -2.0 entry.

The frozen private expected result and witnesses may be consumed only by the coordinator's independent grader after the terminal barrier. Any change needed in the evaluation instrument must be documented as a separate instrument issue; do not silently change the frozen witnesses, public task or decision policy to obtain a hit. Source-causal failures, safe passes and invalid attempts remain distinct outcomes.
